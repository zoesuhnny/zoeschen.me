# zoeschen.me
My personal website: projects, background, and a little bit about me.
Live at [zoeschen.me](https://zoeschen.me).

## Built with
- HTML + CSS
- Hosted on GitHub Pages with a custom domain
- Built in VS Code with help from Claude; design and content tweaks are my own
- Card-style layout inspired by the game *Reigns!*

## Run locally
Clone the repo and open `index.html` in a browser, or serve it locally:

    git clone https://github.com/zoesuhnny/zoeschen.me.git
    cd zoeschen.me
    python3 -m http.server

Then visit http://localhost:8000.

## Structure
    index.html        # main page
    assets/           # images and other static files
    CNAME             # custom domain config
    .github/workflows # deployment workflow
